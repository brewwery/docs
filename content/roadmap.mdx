# Roadmap

## Current: v1.0 — Native macOS App

Brewwery 1.0 is a complete native rewrite in Swift:

- SwiftUI and AppKit app with every screen and workflow from 0.9.7
- Universal binary for Apple Silicon and Intel, macOS 14 or later
- Developer ID signing and Apple notarization
- Automatic app updates with Sparkle
- A typed Homebrew command layer with no shell, and cancellation that stops every child process
- Test suites that never touch the real Homebrew, plus an opt-in live suite

## Next

- **Localized interface** — the languages already available on [brewwery.com](https://www.brewwery.com) inside the app
- **Brewfile workflows** — install from a Brewfile and compare a Brewfile with what is installed

Priorities follow feedback. Suggest a feature in [GitHub Discussions](https://github.com/brewwery/brewwery/discussions) or pick up an [issue](https://github.com/brewwery/brewwery/issues).

## History

### v0.9 — Discover, Favorites, and Package Intelligence
- Discover collections and Favorites
- Taps management, Homebrew Leaves, and installed dependents
- Dock badge for outdated packages
- Streaming progress, cancellation, and timeouts for services and cleanup
- Accessibility improvements to focus, dialogs, and drawers

### v0.8 — Launch Candidate
- Light theme alongside System and Dark
- Theme tokens across all components
- Issue templates and standardized labels

### v0.7 — Private Beta
- Friendlier error messages with expandable details
- History output trimming and faster rendering
- Explicit **Check for updates** action

### v0.6 — Private Alpha
- Install guide, QA checklist, and diagnostics copy

### v0.5 — Distribution and Polish
- macOS packaging, menu bar, keyboard shortcuts, and Settings
- Custom Homebrew path validation

### v0.4 — Search and Discovery
- Homebrew search, install, and uninstall with confirmation
- Streaming progress output

### v0.3 — Cleanup, Doctor, and Brewfile
- Cleanup preview and run, `brew doctor`, Brewfile export and read
- Local operation history

### v0.2 — Updates and Services
- Outdated packages and upgrades
- Service start, stop, and restart

### v0.1 — Foundation
- App shell, sidebar, and status bar
- Homebrew detection and installed package lists

## Out of scope

- Linux and Windows
- Package managers other than Homebrew
- Telemetry, accounts, cloud sync, and paid features
